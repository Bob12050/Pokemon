# Monster Emerald — オリジナルモンスターRPG

ポケットモンスター エメラルド（GBA / 第3世代）の **見た目とシステムを再現** しつつ、
登場する **モンスターはすべて完全オリジナル** に差し替えたブラウザRPGです。
（任天堂／ゲームフリークの著作物は一切使用していません。ドット絵・データはすべて自作です。）

## 遊び方

`index.html` を **ブラウザで開くだけ** で動きます（ビルド・サーバー不要）。

```
# どれかでOK
open index.html          # Mac
xdg-open index.html      # Linux
# もしくは簡易サーバーでも可
python3 -m http.server   # → http://localhost:8000
```

## 操作

| キー | 動作 |
|------|------|
| 矢印キー | 移動 / カーソル |
| Z | A（けってい・はなしかける・すすめる） |
| X | B（キャンセル） |
| Enter | START（メニュー） |

画面下のタッチボタンでも操作できます（スマホ対応）。

## エメラルド再現のポイント

- **GBA解像度 240×160** を基準にしたピクセルパーフェクト描画
- **タイルマップのフィールド探索**（グリッド移動・カメラ追従・草むらエンカウント・ワープ・看板/NPC会話）
- **ターン制バトル**（GBA風の敵右上・自分左下・HPボックス・コマンドUI）
- **第3世代の戦闘システムを忠実に再現**
  - 種族値 / 個体値からのステータス計算（第3世代の計算式）
  - 物理・特殊が **タイプで決まる** 第3世代仕様
  - 17タイプの相性表（フェアリー無し）・タイプ一致（STAB）・急所・乱数補正
  - 状態異常（どく・やけど・まひ・ねむり・こおり・こんらん）と能力ランク変化
  - 第3世代の **捕獲判定式**（HP・状態・ボール補正・4回判定）
  - 経験値グループ別のレベルアップ・技習得・**進化**
- **スタートメニュー**：モンスター（詳細・ステータス・技）／バッグ（道具使用）／レポート（セーブ）／ずかん
- `localStorage` への **セーブ＆コンティニュー**
- **トレーナー戦**：フィールドの視線（！マーク）で勝負開始、複数手持ち・連戦、勝利で賞金
- **街の施設**：モンスターセンター（無料回復）／フレンドリィショップ（賞金で道具購入）
- **バトル演出**：登場スライドイン・ひんしフェードアウト・効果ばつぐんの画面フラッシュ

> `src/audio.js` にチップチューンのBGM/効果音エンジンを用意していますが、現在は未接続（無音）です。

→ ニジイロシティ（センター・ショップ・民家）と進めます。

## 登場モンスター（オリジナル）

御三家3系統（くさ／ほのお／みず・各3段進化）＋ 野生モンスター多数。

| No. | 名前 | タイプ | 進化 |
|----|------|--------|------|
| 1-3 | スプラウト → リーフロックス → フロラビースト | くさ→くさ/あく | Lv16 / Lv32 |
| 4-6 | エムビット → フラリット → パイロサーン | ほのお→ほのお/かくとう | Lv16 / Lv32 |
| 7-9 | ドリブレット → アクアフィン → タイダロア | みず→みず/じめん | Lv16 / Lv32 |
| 10-21 | ニブレット / フリトル / バズル / スパーキット / コブライト / グルーモス / ウィスパー / ドラットレット ほか | 各種 | 一部進化あり |

## ファイル構成

```
index.html        エントリ（スクリプトの読み込み順を定義）
style.css         GBA風の外枠・タッチUI
src/data.js       タイプ相性・わざ・モンスター種族データ・アイテム
src/sprites.js    モンスター/プレイヤー/タイルのドット絵生成
src/engine.js     ゲームループ・入力・UI描画・ステータス計算・セーブ
src/maps.js       タイル描画・マップ・エンカウントテーブル
src/battle.js     ターン制バトル
src/overworld.js  フィールド探索
src/menu.js       スタートメニュー・各サブ画面
src/main.js       タイトル・最初のモンスター選択・起動
```
